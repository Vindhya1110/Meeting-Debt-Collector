# 4-Minute Demo Script

**Setup before you start**: server running at `http://localhost:8000` (from
`agent/`), dashboard open in a browser tab, `MOCK_MODE=false` (or `true` if you
want zero API risk). This script uses the dashboard's manual-transcript path —
the Chrome extension drives the exact same pipeline from a live Meet/Zoom/Teams
call instead, with every meeting/commitment/person mirrored live into Notion.

## 0:00 — The hook (15s)
"60-70% of verbal commitments made in meetings are forgotten within 48 hours.
This agent sits between 'I'll do that' and the follow-up — it doesn't just take
notes, it watches."

## 0:15 — Create a meeting from a real transcript (60s)
1. Go to **Run a Meeting**.
2. Title: `Sprint Review — Demo`. Type: `Sprint Review`. Owner: `Alice`.
3. Pick **Clean transcript** from the sample dropdown, click **Create & Process**.
4. Switch to **Commitment Feed** — point out:
   - Each commitment shows the *verbatim quote*, not a paraphrase.
   - Deadlines like "Thursday end of day" were resolved to real timestamps.
   - Bob's integration-testing commitment is linked to Alice's API commitment
     (dependency resolution) — mention the cascade will trigger automatically
     if Alice's task slips.

## 1:15 — Live chunk ingestion + agenda coverage (45s)
1. Back on **Run a Meeting**, pick the same meeting in "Live Chunk Ingestion."
2. Paste a chunk like: `Rohith: We'll handle the deployment, don't worry about it.`
3. Send it — show the **ownerless commitment alert** fires to Slack.
4. Go to **Agenda Coverage**, load the meeting — show which required agenda
   slots (blockers, owners, testing, next scope) are covered vs still pending.

## 2:00 — The clock trick (60s)
1. Go to **Clock & Demo**.
2. Set "Advance by hours" to `24`, click **Advance Clock + Run Watch Loop**.
3. Switch to **Commitment Feed** — commitments now show `nudged` status.
   Check Slack — a warm, personalized nudge quoting their own words arrived.
4. Advance another `20` hours. Watch a commitment go to `escalated`, then
   advance further to see one marked `missed` — and show that anything
   depending on it just got its deadline pushed automatically (cascade).

## 3:00 — Reports and the coaching angle (45s)
1. Go to **Reports**. Show the per-person follow-through table and the
   AI-generated coaching summary — framed constructively, never "blame."
2. Show the meeting debt score table — this meeting's follow-through rate,
   and the "consider async" suggestion for chronically low-yield meetings.

## 3:45 — Close (15s)
"Everything here — extraction, deadline resolution, nudge writing, coaching
reports — is generated by three focused LLM calls, one similarity engine
reused three ways, and a scheduler that never sleeps. Not a note-taker. A debt
collector."

---

### Fallback if any live API is down
Restart with `MOCK_MODE=true`. The full pipeline still runs end-to-end with
canned but realistic responses — nothing in the demo script changes.
